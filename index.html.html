1. แนวคิดและเนื้อหาเกม (Game Concept & Storyline)

ชื่อเกมและเรื่องราว (Storyline)

ชื่อเกม: Cyber Logic Quest: พิชิตอาณาจักรไซเบอร์
รูปแบบเกม: 2D Top-Down Cyber-Puzzle Adventure
เรื่องราวสั้น: "น้องโค้ดดี้" (Codie) นักเรียนชั้น ป.5 ถูกดึงเข้าไปในโลกดิจิทัลของโรงเรียนที่กำลังถูก "จอมลวงโลก Fake News" และ "ไวรัสสแปม" ยึดครอง ระบบรักษาความปลอดภัยปิดตัวลง! โค้ดดี้ต้องใช้ **เหตุผลเชิงตรรกะ** ในการแก้ปริศนา ค้นหา **กุญแจตรรกะ 3 ดอก** และตอบคำถามความปลอดภัยไซเบอร์เพื่อเปิดประตู **Master Firewall** กอบกู้ระบบโรงเรียนให้กลับมาปลอดภัย

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

สอดคล้องกับตัวชี้วัด กลุ่มสาระการเรียนรู้วิทยาศาสตร์และเทคโนโลยี (วิทยาการคำนวณ) ชั้น ป.5:

  • ตัวชี้วัด ว 4.2 ป.5/1: ใช้เหตุผลเชิงตรรกะในการแก้ปัญหา การอธิบายการทำงาน การคาดการณ์ผลลัพธ์จากปัญหาอย่างง่าย
  • ตัวชี้วัด ว 4.2 ป.5/2: ออกแบบ และเขียนโปรแกรมอย่างง่าย โดยใช้ซอฟต์แวร์หรือสื่อ และตรวจหาข้อผิดพลาดและแก้ไข
  • ตัวชี้วัด ว 4.2 ป.5/3: ใช้เทคโนโลยีสารสนเทศอย่างปลอดภัย มีมารยาท เข้าใจสิทธิและหน้าที่ของตน เคารพในสิทธิของผู้อื่น แจ้งผู้เกี่ยวข้องเมื่อพบข้อมูลหรือบุคคลที่ไม่เหมาะสม

ระบบการเล่น และกติกา (Gameplay & Rules)

🎮 การควบคุม ใช้ปุ่ม Arrow Keys หรือ WASD ในการเดิน 4 ทิศทาง (ขึ้น, ลง, ซ้าย, ขวา)
🏆 เงื่อนไขการชนะ เก็บกุญแจตรรกะครบ 3 ดอก + ตอบคำถามจุดเช็กพอยต์ถูกต้อง + เดินเข้าประตู Master Firewall
❌ เงื่อนไขการแพ้ พลังชีวิต (Lives) ลดลงเหลือ 0 จากการชนไวรัส หรือ เวลา (Timer 120 วิ) หมดลง

แนวทางการเขียนบล็อก Scratch (Scratch Block Architecture)

// 1. การเคลื่อนที่และตรวจจับการชนกำแพง (Player Movement)
when 🚩 clicked
set [Lives v] to (3)
set [Score v] to (0)
forever
  if <key [right arrow v] pressed?> then
    change x by (4)
    if <touching color [#Walls] ?> then
      change x by (-4) // ชนกำแพง ให้ถอยกลับ
    end
  end
  if <touching [Virus_Patrol v]?> then
    change [Lives v] by (-1)
    broadcast [PlayDamageSound v]
    go to x: (-200) y: (150) // Respawn
  end
end
// 2. ระบบเช็กพอยต์คำถามไซเบอร์ (Quiz Broadcast)
when 🚩 clicked
forever
  if <touching [Quiz_Gate v]?> and <(IsQuizActive) = [False]> then
    set [IsQuizActive v] to [True]
    broadcast [AskCyberQuestion v]
  end
end

when I receive [AskCyberQuestion v]
ask [ข้อใดคือการตั้งรหัสผ่านที่ปลอดภัยที่สุด?] and wait
if <(answer) = [3]> then
  change [Score v] by (100)
  say [ถูกต้อง! รหัสผ่านผสมผสานสัญลักษณ์ปลอดภัยที่สุด] for (2) secs
else
  say [ยังไม่ถูกต้อง! ลองทบทวนเหตุผลอีกครั้งนะ] for (2) secs
end
set [IsQuizActive v] to [False]

5. คำแนะนำสำหรับการจัดกิจกรรมการเรียนรู้ (Pedagogical Guide)

แนวทางการนำเกมไปใช้จัดกิจกรรมในชั้นเรียน (4 คาบเรียน) พร้อมกิจกรรม Unplugged และเกณฑ์การประเมิน

1

ขั้นที่ 1: Unplugged Analysis

ให้นักเรียนจับคู่เขียน **Flowchart (ผังงาน)** บนกระดาษเพื่อวางแผนขั้นตอนการแก้ปัญหา เช่น "หากพบไวรัสให้เดินหลบ อย่างไร" หรือ "การตรวจสอบข่าวปลอมมีขั้นตอนอย่างไร"

2

ขั้นที่ 2: Plugged Exploration

ให้นักเรียนเข้าทดลองเล่นเกม **Cyber Logic Quest** เพื่อวิเคราะห์เงื่อนไข If-Then-Else ที่ซ่อนอยู่ในเกม และตอบคำถามจุดเช็กพอยต์ภัยไซเบอร์

3

ขั้นที่ 3: Scratch Modification

ให้นักเรียนเปิดโปรเจกต์ Scratch ต้นแบบ ปรับแต่งเงื่อนไข เช่น เพิ่มด่านคำถามใหม่เกี่ยวกับพฤติกรรมการบูลลี่ออนไลน์ (Cyberbullying) หรือปรับความเร็วศัตรู

4

ขั้นที่ 4: Reflection & Discussion

อภิปรายสรุปบทเรียนร่วมกันในห้องเรียน: "เหตุใดตรรกะและอัลกอริทึมจึงช่วยให้เราตัดสินใจเลือกรับข้อมูลบนโลกออนไลน์ได้อย่างปลอดภัย?"

เกณฑ์การประเมินผลนักเรียน (Assessment Rubric - ป.5)

ประเด็นการประเมิน ดีมาก (4) ดี (3) พอใช้ (2) ปรับปรุง (1)
1. การใช้เหตุผลเชิงตรรกะ เขียน Flowchart แก้ปัญหาได้ถูกต้องตามลำดับขั้นตอนชัดเจนทุกจุด เขียน Flowchart ได้ถูกต้องเป็นส่วนใหญ่ มีข้อผิดพลาดเล็กน้อย เขียน Flowchart ได้ แต่สลับลำดับเงื่อนไขบางจุด ไม่สามารถวางลำดับขั้นตอน Flowchart ได้
2. ความรู้ความเข้าใจภัยไซเบอร์ ตอบคำถามเช็กพอยต์ไซเบอร์ถูกต้องครบทุกข้อ พร้อมอธิบายเหตุผลได้ถูกต้อง ตอบคำถามถูกต้อง 80% อธิบายเหตุผลได้เป็นส่วนใหญ่ ตอบคำถามถูกต้อง 50% ต้องได้รับการแนะนำบางส่วน ตอบคำถามถูกต้องน้อยกว่า 50% และยังไม่เข้าใจเรื่องรหัสผ่าน/ข่าวปลอม
3. การประยุกต์ใช้ใน Scratch แก้ไขบล็อกเงื่อนไข If-Then-Else และสร้างคำถามใหม่ในโปรแกรมได้สมบูรณ์ แก้ไขบล็อกเงื่อนไขได้ถูกต้อง โดยมีครูชี้แนะเล็กน้อย ปรับเปลี่ยนค่าตัวแปรได้ แต่ยังสับสนการใช้ Broadcast ยังไม่สามารถแก้ไขบล็อกโปรแกรม Scratch ได้
